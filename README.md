# Computer Vision Projects

Welcome to my collection of Computer Vision experiments and applications. 
Powered by **OpenCV**, **Google MediaPipe**, and **PyAutoGUI**.

## Projects

Here is a list of the current applications included in this repository:

| Project Name | Description | Key Gesture |
| :--- | :--- | :--- |
| **[Control Cursor with Gestures](./control-cursor-with-gestures)** | A virtual mouse implementation. Move the cursor with your hand and click by releasing a pinch. | **Pinch** |
| **[Control Music with Gestures](./control-music-with-gestures)** | A music controller that toggles Play/Pause on your system based on hand states. | **Open Palm** |

---

## Tech Stack & Dependencies

All projects in this repository share a common set of libraries focused on computer vision and automation.

* **Python 3.10+**
* **OpenCV** (`opencv-python`)
* **MediaPipe** (`mediapipe`)
* **PyAutoGUI** (`pyautogui`)
* **NumPy** (`numpy`)

### Global Installation

To run any of the projects, ensure you have the required dependencies installed:

```bash
pip install opencv-python mediapipe pyautogui numpy
```
## Getting Started
Clone the repository:

```Bash
git clone [https://github.com/bl4ze4447/computer-vision.git](https://github.com/bl4ze4447/computer-vision.git)
cd computer-vision
```
Navigate to a project: Choose the project you want to try and navigate to its directory:

```
Bash
# Example: To try the cursor controller
cd control-cursor-with-gestures
```
Run the script: Follow the specific README instructions inside each folder.

## Notes

Lighting: For best performance, ensure your hand is well-lit and clearly visible to the webcam/video input.
